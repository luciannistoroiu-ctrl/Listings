# Amazon Listing Images Integration

## Overview

The `amazon-listing-images` skill has been integrated into the Listings project. This skill provides comprehensive Amazon product listing image optimization with strategic visual content planning, conversion-focused design, and performance testing methodologies.

## Skill Installation

The skill is installed globally at: `~/.agents/skills/amazon-listing-images`

```bash
npx skills add nexscope-ai/Amazon-Skills --skill amazon-listing-images -g
```

## Core Capabilities

### 1. Strategic Visual Content Planning & Shot List Development
- Comprehensive image strategy development based on customer psychology and conversion optimization
- Professional shot list creation with detailed photography briefs and technical specifications
- Visual hierarchy planning and customer journey optimization through strategic image sequencing
- Brand consistency frameworks and visual identity development for competitive differentiation

### 2. Conversion-Focused Image Design & Infographic Creation
- Data-driven infographic design with feature comparison and benefit visualization strategies
- Mobile-first image optimization and responsive visual content development
- Professional lifestyle photography planning with audience-specific scene development
- Visual storytelling frameworks and emotional engagement strategies for maximum conversion impact

### 3. Performance Optimization & A/B Testing Strategy
- Image performance tracking and conversion analytics with systematic optimization frameworks
- A/B testing methodologies for visual elements and strategic image variation development
- Competitive visual analysis and market positioning through differentiated image strategies
- Ongoing optimization cycles and performance improvement through data-driven visual refinements

## How to Use

Invoke the skill directly with Amazon product image requests:

```
/amazon-listing-images "Create comprehensive image strategy for [product] - need shot list, infographics, lifestyle scenes"
```
